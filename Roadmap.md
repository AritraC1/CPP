# DSA Roadmap

## Phase 0 — C++ Refresher (3-4 days max)
- [ ] Loops, functions, pointers/references (just enough comfort, not mastery)
- [ ] Pass-by-value vs pass-by-reference
- [ ] STL: `vector`, `pair`
- [ ] STL: `map` / `unordered_map`, `set` / `unordered_set`
- [ ] STL: `queue`, `stack`, `priority_queue`, `deque`
- [ ] Built-ins: `sort()`, `lower_bound()`, `upper_bound()`, basic string functions

---

## Phase 1 — Foundations
- [ ] Time & Space Complexity (Big-O, how to analyze your own code)
- [ ] Arrays — basics, traversal, in-place modification
- [ ] Two Pointers pattern
- [ ] Sliding Window pattern
- [ ] Prefix Sum pattern
- [ ] Strings — basics, common manipulation problems
- [ ] Hashing (HashMap / HashSet use-cases, frequency counting)
- [ ] Sorting algorithms (merge sort, quick sort — understand, don't memorize implementation)
- [ ] Binary Search (on arrays, and on answer — a very underrated pattern)

## Phase 2 — Recursion & Backtracking (your known wall — slow down here)
- [ ] Recursion basics — trace by hand first, draw call stacks, predict output before solving
- [ ] Recursion on arrays/strings (reverse, subsets, permutations)
- [ ] Backtracking pattern (subsets, permutations, combinations, N-Queens, Sudoku-style problems)

## Phase 3 — Linked Structures
- [ ] Linked List — singly (traversal, insertion, deletion)
- [ ] Linked List — reversal, cycle detection (Floyd's), merge, fast-slow pointers
- [ ] Doubly Linked List
- [ ] Stack — applications (valid parentheses, next greater element, monotonic stack)
- [ ] Queue — applications, circular queue
- [ ] Monotonic Stack / Queue pattern

## Phase 4 — Trees
- [ ] Binary Tree — traversals (inorder, preorder, postorder, level-order/BFS)
- [ ] Binary Tree — height, diameter, views (top/bottom/left/right)
- [ ] Binary Search Tree (BST) — insert, delete, search, validate
- [ ] Tree recursion patterns (LCA, path sum, root-to-leaf paths)
- [ ] Trie (prefix tree) — insert, search, common use-cases
- [ ] Heaps / Priority Queue — min-heap, max-heap, k-th largest/smallest problems

## Phase 5 — Graphs
- [ ] Graph representation (adjacency list/matrix)
- [ ] BFS on graphs
- [ ] DFS on graphs
- [ ] Cycle detection (directed & undirected)
- [ ] Topological Sort
- [ ] Union-Find / Disjoint Set (DSU)
- [ ] Shortest path — Dijkstra
- [ ] Shortest path — Bellman-Ford (know conceptually)
- [ ] Minimum Spanning Tree — Kruskal's / Prim's (know conceptually)

## Phase 6 — Dynamic Programming (the big one — go slow, this is pattern recognition)
- [ ] DP basics — memoization vs tabulation, identifying overlapping subproblems
- [ ] 1D DP (climbing stairs, house robber, fibonacci-style)
- [ ] 2D DP (grid paths, unique paths)
- [ ] Knapsack pattern (0/1 knapsack, subset sum, partition)
- [ ] Unbounded Knapsack (coin change, rod cutting)
- [ ] Longest Common Subsequence (LCS) and string DP variants
- [ ] Longest Increasing Subsequence (LIS)
- [ ] DP on trees (basic exposure)
- [ ] DP on intervals (matrix chain multiplication style)

## Phase 7 — Greedy
- [ ] Greedy basics — activity selection, interval scheduling
- [ ] Greedy with sorting (merge intervals, meeting rooms)

## Phase 8 — Advanced / Polish (only after everything above is solid)
- [ ] Bit Manipulation (AND/OR/XOR tricks, common bit problems)
- [ ] Segment Tree / Fenwick Tree (BIT) — only if aiming for CP later
- [ ] Sliding Window Maximum (advanced monotonic deque usage)
- [ ] Math for DSA (GCD/LCM, sieve of Eratosthenes, modular arithmetic)
